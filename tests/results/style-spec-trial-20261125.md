# style-spec を見て session を 4 回作った結果（2026-11-25）

目的: 足切りなし・`docs/style-spec.md` を参照するワークフローで、実際の依頼（「Perfumeのコミュニケーションという曲にあうシガーのデコレーションを考えたい。衣装はこんな感じ」+ `tmp/image.png`）を、毎回 brief から書き直して 4 回流した。過去の session / brief は流用していない。

一覧画像（`t*.webp`）は、実際の生成物なので Git 管理外（手元にだけある）。brief（プロンプト）は同じフォルダにある。

評価は**自己評価（暫定）**。人間のレビューではない。「物体混入」は、木枠・額縁・葉巻・箱・紙の上の立体物・写真のように、平面の柄ではなくなったもの。

## 設定

- モデル: DreamShaper XL Turbo-Lightning（1152x768、steps 6、cfg 2、dpmpp_sde）。分類器・足切りなし。
- 各 session は 8 アイデア = 8 プロンプト = 8 枚。brief は同じフォルダの `perfume-communication-t*.json`（プロンプトは `items[].text`）。
- style-spec の反映: 色は青緑・深緑・赤紫・黒と白（衣装を見て決めた）、面はベタ塗り、反復は規則的にしない、大きな形・流れ・縦縞・花・ハートを使う、風景の語を避ける。

## 分かったこと

1. **プロンプトに `cigar box panel` と書くと、箱・葉巻・木枠の写真になりやすい。** 4 session（32 枚）のうち、物体が混入したのは約 5 / 8。
2. 同じアイデア・同じ seed のまま、この語だけを消した t5・t6（16 枚）では、木枠・葉巻が 0 枚になり、物体混入が 2〜3 / 8 に減った。題材は 1 つで、自己評価なので、観察として扱う。
3. 語を消したあとの弱点は、style-spec が避けるとしている方向と重なる: 風景に化ける（t5-03、t5-04）、立体・エンボス（t5-05、t6-08）、規則反復（t5-05、t2-07）。
4. 前の `tests/results/e2e-all-images.webp` は、`tests/fixtures.py` の合成 brief（動作確認用の仮のアイデア）で作った画像で、実際のお題の brief ではない。偏りは、そのためと考えられる。
5. 過去の `good-archive` の良い回は、足切りが物体混入の画像（上の 1）を隠していた可能性がある。落ちた画像が削除済みで確かめられない。

## 反映したこと

- `session.py` が AI に出す依頼文に、style-spec の「好みの記録」の表から作った描き方の指針を入れた（`style_guide`）。
- 依頼文に「箱・額縁・枠・木・葉巻など、物体を連想させる語は書かない」を追加した。
- `design-workflow` の SKILL に、brief は毎回一から書く、style-spec を読む、用途の語を書かない、を追加した。
- `docs/style-spec.md` に、物体の混入の観察を足した。
