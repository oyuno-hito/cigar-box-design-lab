# style-spec を直すループ（2026-11-25）

流れ: 結果を見る → `docs/style-spec.md` を直す → コミット → 新しい brief を一から書いて 3 session × 6 枚を生成 → 色の集計（`tools/palette_stats.py`）と目視（自己評価・暫定）→ 次の修正へ。足切りなし。モデルは DreamShaper XL Turbo-Lightning。

画像の一覧（`*.webp`）は、実際の生成物なので Git 管理外。brief と集計は、`style-spec-loop-20261125/` にある。

## 出発点（直前の 6 session、48 枚）

`style-spec-trial-20261125.md` の t1〜t6。色の集計（`style-spec-trial-20261125/palette-t1-t6.txt`）:

- 赤紫が主な色の画像 96%、青緑が 94%。この 2 色の組み合わせが 79%。
- 原因は、参考画像（衣装）の色を、私が全アイデアにそのまま入れたこと。style-spec の `color` の句の案に、turquoise / magenta が例として入っていたことも、影響した可能性がある。

## 第 1 回の修正（色の偏り）

- 軸の語彙に「色の多様性（1 session の中）」を追加。
- 好みの記録に、参考画像の色は「色の枠」として使い、アイデアごとに地と主色・差し色の組を変える、を追加（観察）。
- `color` の句の案の色名を `<color A>` `<color B>` に変更。色名は例で、既定の配色ではないと明記。
- `design-workflow` の SKILL に、色の組を変えることと、`palette_stats.py` での確認を追加。

## 第 1 回の結果（r1a・r1b・r1c、各 6 枚、すべて Perfume）

色の集計（`style-spec-loop-20261125/palette-r1.txt`）は、偏りが減った。

| 指標 | 出発点（48 枚） | 第 1 回（18 枚） |
| --- | --- | --- |
| 赤紫が主な色の画像 | 96% | 17% |
| 青緑が主な色の画像 | 94% | 56% |
| 最も多い色の組み合わせ | 赤紫 + 青緑 79% | 青緑のみ 33% |
| 地 | 有彩色 60% / 暗い 25% / 明るい 15% | 明るい 56% / 暗い 28% / 有彩色 17% |

目視（自己評価・暫定）では、色は分かれたが、**平面でなくなった画像が多い**。

- 影・グラデーション・立体になったもの: r1a-01・04・05、r1b-03・06、r1c-04・06 ほか約 10 枚。末尾の句が `flat solid color fills, bold clear edges` だけで、`flat` の句（no shadows など）を入れていなかった。
- 物の写真になったもの: r1a-03（リボン）、r1a-06（葉）、r1c-01（しずく）、r1c-03（花）。`one huge` `a single huge` + 物の名詞、`standing` が原因に見える。
- 風景になったもの: r1b-02（彗星 → 山と星空）、r1c-05（横筆 → 丘と雲）。
- 平面で成立したもの: r1a-02、r1b-01、r1b-05、r1c-02（形の語 `chevron` `bars` `bands` `waves`）。成立は 18 枚のうち 4〜8 枚（44% 前後）。

## 第 2 回の修正（物の名指し、影・立体）

- 好みの記録に「具象度（物の名指し）」「面の処理（影・立体）」の行を追加（観察）。
- 次回は、`flat` の句を全アイデアに入れ、物の名詞を形の語に置き換えて試す。

## 第 2 回の結果（r2a Perfume・r2b 夜に駆ける・r2c 紅蓮華、各 6 枚）

色の集計（`style-spec-loop-20261125/palette-r2.txt`）: 最も多い色の組み合わせは 17%（橙 + 青）。3 題材とも、色の枠の中で地と主色が分かれた。色の偏りは、第 1 回の修正で解消した。

目視（自己評価・暫定）:

| 項目 | 第 1 回（18 枚） | 第 2 回（18 枚） |
| --- | --- | --- |
| 物の写真になった | 4 | 0 |
| 影・グラデーション・立体になった | 約 10 | 約 4 |
| **風景になった（丘・山・月夜・夕日・畑）** | 2 | **約 11** |
| 平面の柄として成立 | 約 8 | 約 7（r2a-01・04、r2b-03・05、r2c-02・03 ほか） |

物の名詞を形の語にして、`flat` の句を入れると、物の写真と影は減った。一方で、**形の語（triangles、waves、curved bands、circles）が、山・丘・月・夕日・畑に化けた**。暗い藍の地に黄の円や帯を置くと、夜景になった。

## 第 3 回の修正（風景化）

- 好みの記録に「構図（風景化）」「反復（ブロックの列）」の行を追加（観察）。
- 次回は、全面を同じ密度で埋める構図、縦・斜めの帯、水平の層を避ける、で試す。
