# generated

生成画像の正本です。分類器用などに画像を複製せず、ここに置いたものを参照します。

```text
generated/
  inbox/     生成直後。まだ分類していない
  like/      好き
  dislike/   明確に好みではない
  maybe/     判断保留（分類器の学習には使わない）
```

## ルール

- 画像ごとに、同名の `.json` でメタデータ（プロンプト、生成元、seed、日時）を残す。
- `maybe` は、好みの境界を把握するために残す。
- 分類を変えるときは、ファイルを別のディレクトリへ移す。過去の分類器がどのラベルを使ったかは、`scorers/vNNN/manifest.json` に固定されている。
